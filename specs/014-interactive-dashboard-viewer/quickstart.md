# Quickstart: Static Dashboard Viewer

The Dashboard Viewer is a static React application that allows you to interactively browse the dashboards and artifacts generated by the pipeline.

## Build the UI

The UI is pre-built into `outputs/figures/ui/`. If you modify the source in `src/ui/`, you can rebuild it using:

```bash
cd src/ui
npm install
npm run build
```

## Launch the Viewer

To view the dashboards, you must serve the `outputs/figures` directory with a web server. The simplest way is using Python's built-in server:

```bash
# From the repository root:
python3 -m http.server -d outputs/figures 8080
```

Then, open your browser to:
[http://localhost:8080/ui/index.html](http://localhost:8080/ui/index.html)

## How it Works

1. **Manifest-Driven**: The UI loads `../manifest.json` relative to its location.
2. **Static Images**: It renders the PNG files registered in the manifest.
3. **Clinical Provenance**: Displays warnings, required roles, and generation timestamps alongside every figure.
